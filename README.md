# Премиум VPN для Android

Версия 0.2.1: всё как на компьютере. Герой на кнопке и друзья, серверы шторкой, подписки с остатком гигабайт, статистика, журнал, кристаллы, шесть тем и все настройки.

**[Скачать приложение (APK)](https://github.com/koliberdenko8887-tech/premium-vpn/raw/main/PremiumVPN.apk)**

Откройте эту страницу на телефоне Android, нажмите ссылку, дождитесь загрузки и откройте файл «PremiumVPN.apk». Разрешите установку из этого источника, если Android попросит.

Приложение подписано собственным ключом, поэтому Play Защита может показать предупреждение. Нажмите «Всё равно установить».

Обновление ставится поверх старой версии, серверы и подписки сохраняются. Новая подписка добавляется в приложении: «Ещё» → «Подписки» → вставьте ссылку → «Добавить».
