# Премиум VPN для Android — исходный код (версия 0.2.0)

## Как устроено
- **Ядро** (папка `core`, Go 1.26.1): один файл `libpvcore.so` = sing-box v1.14.3 (туннель, DNS, правила, счётчики)
  + Xray-core v26.3.27 (серверы из подписки: VLESS/Reality/XHTTP, VMess, Trojan, Shadowsocks).
  Разбор подписки и ссылок взят из Windows-версии (links.go, xray.go, countries.go — те же файлы).
  Команды: `run <params.json>` (VPN, настройки как на Windows: DNS, маршруты, фрагментация, шум, Mux), `sub <url>`, `parse` (ссылки из stdin), `ping`, `rping` (пинг через сервер).
  Во время VPN ядро пишет статистику в папку приложения: `stats.json` (дни, серверы) и `live.json` (сессия, скорость, соединения).
- **Приложение** (папка `android`, Java без AndroidX): экран — страница Windows-версии `ui/desktop.html` в WebView.
  `ui/build_phone.py` переделывает её для телефона: `ui/phone/phone.css` (одна колонка, нижняя панель, шторки, ещё 4 темы),
  `ui/phone/phone.js` (функции pvState, pvToggle… поверх моста `PV`, серверы и подписки в localStorage), `ui/phone/sect.js` (настройки).
  Шрифты (OFL) в `ui/fonts`, флаги (flag-icons, MIT) в `ui/flags`, 3D-люди и three.js в `ui/vendor`.
  `PvVpn` — VpnService: Android открывает туннель, дескриптор передаётся ядру через абстрактный unix-сокет
  (SCM_RIGHTS), сеть телефона (интерфейсы, DNS) ядро получает от приложения (Android 11+ закрывает netlink).
  Приложение исключено из своего же VPN (addDisallowedApplication), поэтому ядро ходит к серверу напрямую.
  `PvTile` — кнопка в шторке быстрых настроек. Сайты anthropic.com, claude.ai, claude.com идут мимо VPN (как на Windows).

## Сборка (Linux)
1. Ядро: `cd core && GOTOOLCHAIN=go1.26.1 CGO_ENABLED=0 GOOS=android GOARCH=arm64 go build -tags with_gvisor,with_quic,with_utls,with_clash_api -trimpath -ldflags "-s -w -buildid=" -o libpvcore.so .`
2. Экран: `python3 ui/build_phone.py` → `android/assets/app.html` и `girls3d.json.gz`. Посмотреть в браузере: открыть app.html#demo рядом с распакованным girls3d.json.
3. APK: `apt install aapt apksigner zipalign dalvik-exchange`, android.jar API 34 (github Reginer/aosp-android-jar) в `sdk/android-34.jar`,
   `KS_PASS=… KEYSTORE=…/premiumvpn.jks ANDROID_JAR=…/android-34.jar android/build.sh` → `android/build/PremiumVPN.apk`.
   Подписывать обновления ТОЛЬКО тем же ключом (папка «Ключ подписи»), иначе телефон не даст обновить приложение.
4. Лаборатория: `lab/harness.py` (Linux, root) — открывает TUN как Android, передаёт его ядру, гоняет трафик через VLESS-сервер.

Пока только arm64 (почти все телефоны с 2017 года). Минимум Android 8.
